# Couple's Clash

A two-phone game show for couples. Open the page on both phones: one taps **Host a game**, the other joins with the 4-letter room code or the invite link.

Eight rounds: Know Me Best, Top of the List, Pick Three, Rank It, Same Page, Fib Detector, The Draft, On a Scale. Classic, Mixed, or After Dark (18+) question sets.

Single file (`index.html`). Phones connect peer-to-peer via PeerJS; no server needed. Same Wi-Fi is the most reliable.
